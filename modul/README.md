# Modul Latihan - Pertemuan 1: JavaScript Dasar

File latihan yang dikerjakan selama mengikuti materi praktikum **JavaScript Dasar**. Setiap file berpasangan (`html` + `js`) dan bisa dibuka langsung di browser lewat Live Server.

| No | Topik | File | Latihan |
|----|-------|------|---------|
| 1 | Variabel & Kondisional | `01_variabel_kondisional.html` / `.js` | Data diri (const/let), cek kelulusan minimal 70, kategori umur, switch-case nama hari (Inggris), kalkulator grade (ternary) |
| 2 | Loop & Fungsi | `02_loop_fungsi.html` / `.js` | Tabel perkalian 1-10, faktorial, cek bilangan prima, FizzBuzz 1-100, kalkulator BMI + event handler |
| 3 | Array & Objek | `03_array_objek.html` / `.js` | Tabel array objek mahasiswa, cari nilai tertinggi (reduce), filter di atas rata-rata, urutkan nama (asc/desc), CRUD sederhana |
| 4 | DOM & API | `04_dom_api.html` / `.js` | Form tambah catatan + validasi, simpan/muat `localStorage`, Fetch API + search + pagination, dark mode toggle |

## Cara Menjalankan

1. Buka folder `modul/` di VS Code.
2. Klik kanan file HTML -> **Open with Live Server**.
3. Buka konsol (**F12 -> Console**) untuk melihat output `console.log`.
